# Showa Street Diorama

Interactive 3D diorama of Japanese street corner featuring Hidamari ramen cafe, an oden cart,...

Demo link: https://tdk211108.github.io/showa-street-diorama/
## Overview

Showa Street Diorama is a WebGL showcase built with Three.js. It recreates the cozy atmosphere of a retro Tokyo neighborhood. Users can inspect detailed 3D architecture, watch falling sakura blossoms, adjust the time of day, and listen to looping background music.

## Tech Stack

| Technology | Role |
| :--- | :--- |
| Three.js | 3D rendering engine and scene graph |
| Vite | Development server and singlefile bundler |
| Web Audio API | Procedural wind and furin bell synthesizer |
| HTML5 Canvas | Procedural textures and dynamic sky canvas |
| JavaScript | Core application logic |

## Getting Started

Follow these steps to run the project locally.

1. Clone the repository to your local machine.
2. Open terminal in the project directory.
3. Install dependencies: `npm install`
4. Start local development server: `npm run dev`
5. Build production bundle: `npm run build`
6. Preview production build: `npx serve dist`

## Controls

1. Left Click and Drag: Rotate camera around the scene
2. Right Click and Drag: Move and pan camera target
3. Scroll Wheel: Zoom in and zoom out
